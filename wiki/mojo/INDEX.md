# Mojo

- [mojo-fundamentals](mojo-fundamentals.md) — Python-compatible systems language by Modular. `def` vs `fn`, variables and `var`, ownership and the four argument conventions (`var`/`mut`/default/`ref`), the `^` transfer sigil, structs and lifecycle traits (`Copyable`/`Movable`/`@fieldwise_init`), traits and generic bounds, compile-time `[...]` parameters, SIMD/GPU primitives, Python interop via `Python.import_module`. Includes a renaming table for older `let`/`borrowed`/`inout`/`owned`/`@value` syntax.
