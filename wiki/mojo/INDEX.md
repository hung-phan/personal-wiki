# Mojo

- [mojo-fundamentals](mojo-fundamentals.md) — Python-compatible systems language by Modular, current as of the stable **1.0.0** release (Aug 2026). `def` (the one function keyword — `fn` is deprecated), variables and `var`, ownership and the four argument conventions (`var`/`mut`/default/`ref`) plus `out`/`deinit` and the `ref` local binding, the `^` transfer sigil, structs and lifecycle traits (`Copyable` explicit-copy vs `ImplicitlyCopyable`, move-only/immovable, `@fieldwise_init`), the `__deinit__` destructor, traits and generic bounds, compile-time `[...]` parameters, SIMD/GPU primitives, and Python interop in depth (`Python.import_module`, `Int(py=...)` value extraction, `PythonObject` aliasing, GIL, numpy zero-copy). Also: everyday Python that differs (catching errors, `Optional`/`None`, template strings `t"..."`, no `match`, `with`, closures/`lambda`, `*args`/`**kwargs`) and tooling (install via pixi, `mojo run`/`build`/`test`-via-`TestSuite`, multi-file packages, `std.` imports). Includes a renaming table for older `fn`/`let`/`borrowed`/`inout`/`owned`/`@value`/`alias`/`__del__`/`__copyinit__`/`StringSlice`/`InlineArray`/`mojo package` syntax.
